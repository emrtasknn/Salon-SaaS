# Architect Skill

Read AGENTS.md and the relevant governance documents first.

Identify:
- requirements
- affected modules
- DB impact
- auth/security impact
- tenant impact
- booking impact
- migration requirements
- tests
- risks

Produce an implementation-ready handoff.

Do not implement production code.
Do not invent requirements.
Escalate conflicts.
