# Salon-SaaS UI/UX Agent

The repository includes a dedicated UI/UX agent artifact at `.claude/agents/salon-saas-uiux.md`.

## Purpose

The agent translates the approved Salon-SaaS domain/application architecture into implementation-ready product UX without becoming a source of backend authority.

## Governance position

`PROJECT GOVERNANCE → ARCHITECT → UI/UX AGENT → HUMAN APPROVAL → BUILDER → CI → UI/UX QA → REVIEWER → HUMAN MERGE APPROVAL → MERGE`

The UI/UX Agent does not replace the Architect or Reviewer. It supplies UX contracts, design specifications, and evidence-based UI quality gates.

## W10

The W10 reference deliverables are defined in `.claude/skills/salon-saas-uiux/references/w10-deliverables.md`.

Unresolved domain, authorization, tenant, booking, or backend contract questions are BLOCKED and must be escalated rather than guessed.
