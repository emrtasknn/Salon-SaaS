# Task — Salon SaaS

## Objective
Make the app installable as a Turkish-language PWA. That means valid metadata, PNG icons, service worker registration and an install prompt. No offline mode or Web Push.

## Risk class
C1. UI/static assets and client-only components; no auth, RLS, tenant, booking, schema or provider change. `public/sw.js` was hardened in #111, so the reviewer must confirm it stays static-only. If any step needs auth/RLS, tenant, booking, Web Push or a new dependency, reclassify as C2 and stop for owner approval.

## Context
- `docs/ADR-043-PWA-FIRST-MOBILE-STRATEGY.md`: PWA-first is approved; Web Push needs separate architecture review (§Web Push constraints).
- `docs/P7_PILOT_ACCEPTANCE_CHECKLIST.md` §D: real-device install/launch acceptance (owner-run).
- Requirement IDs: WP-3 (PWA foundation), P7-§D (prerequisite). Current state: manifest has only an SVG icon; sw.js caches only manifest+SVG; `layout.tsx` has "Create Next App" metadata, `lang="en"`, no manifest link, no SW registration.

## Scope
In:
- `layout.tsx`: Turkish title/description, `lang="tr"`, `manifest: "/manifest.json"`, `appleWebApp` (capable, title, `statusBarStyle`), `icons` incl. `apple` 180px; `themeColor` via the `viewport` export (Next 16).
- PNG icons in `public/icons/`: `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` (artwork inside the 80% safe zone, full-bleed `#171717` background), `apple-touch-icon-180.png`. Generated from the `app-icon.svg` design by `scripts/generate-pwa-icons.mjs`, which uses only `node:zlib`/`node:fs`. No new dependency, and do not import `sharp` (it is only an optional transitive dep of `next`). The PNGs are committed; the script is not wired into `package.json`/build.
- `manifest.json`: Turkish `name`/`short_name`, `lang: "tr"`, `id: "/"`, `scope: "/"`, PNG icons (`any` + `maskable`); keep the SVG.
- SW registration client component: production only, feature-detected (`"serviceWorker" in navigator`, secure context), `register("/sw.js", { scope: "/" })`, failures swallowed silently.
- Install prompt client component: captures `beforeinstallprompt` and shows a "Uygulamayı yükle" button; iOS Safari shows a hint (Paylaş → Ana Ekrana Ekle); dismissible (dismissal kept in `localStorage`, UI-only); hidden in `display-mode: standalone` / `navigator.standalone`; must not cover booking CTAs (respect safe area).
- `sw.js`: add the new PNG paths to `ALLOWED_STATIC_PATHS` with an `image/png` content-type check. Bump `CACHE_NAME` to `salon-saas-pwa-v2` and add v1 to `LEGACY_CACHE_NAMES`. Still never cache navigations, HTML, authenticated pages or `/api/*`; no offline mutations.
- Pure logic in `src/app/pwa/*.ts` (no `page.tsx`/`route.ts` in that folder), unit-tested in the vitest node env.
- Responsive check from 320 to 1280px.

Out: Web Push, permission prompts, notification routing, push-subscription storage, offline mode/fallback page, any auth/RLS/tenant/booking change, `next.config` changes, native apps.

## Acceptance criteria
- [ ] Manifest is valid. Lighthouse/DevTools "Installable" passes locally (`npm run build` + `npm start`, Chrome).
- [ ] `<html lang="tr">`, Turkish metadata, manifest link, `theme-color` and apple-touch-icon are in rendered `<head>`; no Next 16 metadata/viewport warnings in the build.
- [ ] Every manifest icon file exists, and its PNG IHDR size matches the declared `sizes`. Every PNG is in the sw.js allowlist.
- [ ] sw.js still returns early for non-GET, cross-origin, `navigate`, `text/html` Accept, query strings and non-allowlisted paths (incl. `/api/*`).
- [ ] SW is not registered in dev. The prompt is hidden when standalone, after dismissal, or when unsupported. The iOS hint shows only on iOS Safari.
- [ ] Layout usable at 320, 375, 768 and 1280px; the prompt does not obscure primary actions.
- [ ] `npm run lint`, `npm run typecheck`, `npx vitest run src/app/pwa` (with `DATABASE_URL` unset) and `npm run build` all pass.
- [ ] Reviewer reports no blocking findings.
- [ ] Real-device install evidence (P7 §D) is left to the owner and is not claimed by agents.
- [ ] No unrelated changes, no new dependency.
